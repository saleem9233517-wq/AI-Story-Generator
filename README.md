# 🤖 AI Story Generator

An AI-powered web application that generates creative stories based on the user's selected idea, genre, length, tone, characters, setting, writing style, and language.

## ✨ Features

- 📝 AI Story Generation
- 🎭 Multiple Genres
- 🎨 Different Writing Styles
- 🌐 Multiple Languages
- 👤 Character Customization
- 📚 Story History
- ✏️ Edit Generated Stories
- 🔄 Regenerate Stories
- 📋 Copy Story
- 📄 Download Story as PDF, Word, or TXT
- 🎙️ Convert Stories to Voice
- 🎬 AI Scene Generation
- 🖼️ Scene Image Generation
- 🎥 Story-to-Scene Workflow
- 🗑️ Delete Stories
- 💾 SQLite Database

## 🛠️ Technologies Used

- Python
- Flask
- OpenAI API
- SQLite
- HTML
- CSS
- JavaScript
- pyttsx3
- ReportLab
- python-docx
